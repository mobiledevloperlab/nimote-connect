## CLI preview

This prerelease provides CLI installers for macOS and Linux on arm64 and amd64. Each package contains both Nimote Connect and NimoteHost.

Download the archive and its matching SHA-256 file. Verify the archive, extract it, and run `./install.sh` as your normal user. Use a compatible NimoteCode client to pair and connect.

All packages passed archive and checksum validation. Both macOS architectures passed CLI version checks, with amd64 tested under Rosetta. The Linux packages were cross-compiled. Native Linux runtime tests and end-to-end connection tests for these artifacts are pending.
