# Nimote Connect 1.2.1

Security update for the production DERP map trust configuration.

- Updates the embedded production DERP map verification key.
- Keeps the fixed Firebase release URL and control plane unchanged.
- Provides CLI packages for macOS, Linux and Windows on amd64 and arm64.
- Compatible with NimoteCode 2.5.0.

Users of 1.2.0 should upgrade to 1.2.1. Verify each archive with its matching
`.sha256` file before installing.
